# Pi Coding Agent

Configuration and tools for a Pi harness.

## Setup

1. Follow the [official instructions](https://pi.dev/packages) to install Pi.
2. Copy `models.json` to `~/.pi/agent/`
3. (If using PlatformAI) Follow the instructions [here](https://docs.google.com/document/d/1A3jI_zVPrAxL3VguUCkiovJWTSK-cOvoJvXzC5m7cEo/edit?tab=t.8e5ldvvotgtu#heading=h.p4qzxtft095o)
4. Copy the `.agents` directory into the root of your repo
5. Copy the `pi/.pi` directory into the root of your repo
6. Amend `<your-repo-dir>.pi/settings.json` as required
7. Start `pi` in a shell - extensions will be installed
